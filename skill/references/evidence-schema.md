# 证据字段模板

## 数值正确性

- 样本/窗口数；
- 浮点与定点类别一致率；
- 最大绝对误差与通过阈值；
- 金样文件和测试脚本路径。

## 性能

- HLS 周期、目标时钟与换算延迟；
- 首次冷启动时间；
- 稳态均值/P50/P95/最大值；
- 整机端到端延迟；
- 基线和加速版本的测量条件。

## 实现

- FPGA 型号与工具版本；
- WNS/TNS；
- LUT、FF、BRAM、DSP；
- DMA/IP 名称、地址和数据宽度。

## 实板运行

- 请求后端、实际后端、回退原因；
- PL 调用计数；
- 摄像头/IMU 链路状态；
- 运行时长和停止原因；
- 丢样、CRC、乱序和队列丢弃。
