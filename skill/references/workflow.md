# 审计工作流

## 输入

- 板端只读快照；
- HLS/RTL 和 Vivado 工程；
- bit/hwh/xsa；
- PS 运行代码、模型和固件；
- 自检、实时记录、时序/资源报告；
- 比赛提交规则。

## 执行

1. 建立要求—证据对应表。
2. 对板端当前产物和电脑端黄金产物做 SHA256 比对。
3. 用板端金样证明定点算子正确，用实时日志证明主程序确实调用该算子。
4. 汇总数值误差、HLS 周期、板端稳态延迟、端到端延迟、时序和资源。
5. 保留软件基线与硬件失败后的回退路径。
6. 排除数据集、事件图像、备份、缓存、临时下载和账号信息。
7. 将绝对路径脚本改为相对路径或明确的环境变量。
8. 在新目录执行发布校验，生成哈希清单并二次解压复验。

## 输出

- 可公开工程包；
- 发布清单和限制说明；
- 可定位到源报告的性能表；
- 构建/板端运行/故障恢复步骤；
- ZIP 与 SHA256。
