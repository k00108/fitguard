# 数据、隐私与公开边界

## 本包包含

- 训练后 CNN 权重、归一化参数和架构描述；
- 随机森林基线模型；
- 18 组匿名金样；
- HLS、实现、板端自检和实时运行汇总；
- 数据采集与质量门控代码。

## 本包不包含

- 未经授权的原始人物视频、可识别人脸图像和可识别个人身份的事件截图；
- M01–M06 的完整个人原始数据；
- `dataset*`、`fitguard_marked_events`、私有日志、Notebook 缓存和历史备份；
- 任何账号、密码或密钥。

## 公开策略

1. 若比赛仅要求可运行与可验证，公开模型、金样、采集代码和验证报告即可。
2. 报告与海报中的系统演示截图仅用于说明运行状态，公开前应确认相关授权并避免出现可识别个人身份的信息；若要求从头训练，应先取得被测者授权，再发布去标识化的特征窗口或合成示例，不直接发布人脸视频。
3. 板端时间曾不准确，因此板端时间戳只用于相对时序，不作为试验发生日期证据。
4. 当前数据规模适合原型验证，不应宣称临床泛化能力。

## 固件说明

`software/esp32_reference/` 来自队友交付的无线 IMU 参考固件，用于说明被测者节点与 USB 网关之间的数据链路。公开前应由负责固件的队员确认实际烧录版本、波特率、BLE 名称、MPU6050 地址和引脚定义。
