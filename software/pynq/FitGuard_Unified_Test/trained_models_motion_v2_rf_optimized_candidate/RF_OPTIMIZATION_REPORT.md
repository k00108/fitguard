# FitGuard 随机森林优化候选报告

## 状态

- 本目录是候选版，没有覆盖原随机森林。
- 摄像头跟踪、数据采集、PL、CNN均未修改。
- 评价数据仍为M01–M03的25段合格实测数据、947个真实重叠窗口。
- 板载错误年份不参与淘汰，其余质量门槛保持不变。

## 优化内容

1. 保留原有311维IMU+视觉融合特征。
2. 为每个完整试次分配相同总训练权重，防止窗口较多的试次主导训练。
3. 搜索树的特征采样比例、叶节点大小、深度和分裂准则。
4. 将原模型风格的基础森林与稳健森林做概率级融合：基础森林25%，稳健森林75%。
5. 保留纯NumPy扁平模型，PYNQ端不需要scikit-learn。

## 部署验证

- NumPy与scikit-learn类别一致率：100%。
- 最大概率误差：2.96e-8。
- 本机纯NumPy批量测试：约7.19 ms/窗口。
- 当前窗口更新间隔约640 ms，因此计算余量充分；仍需在PYNQ实机复测延迟。

## 使用限制

融合权重是在M01–M03上选择的，因此不能把99.68%描述为独立外部测试成绩。M04–M06补测后，应先冻结本候选，再用新受试者检验；建议将M06完全锁作最终测试。只有新增人员验证仍优于原模型，才替换正式随机森林。

## 文件

- `fitguard_motion_v2_rf_base_numpy.npz`：基础森林。
- `fitguard_motion_v2_rf_robust_numpy.npz`：试次均衡稳健森林。
- `rf_blend_config.json`：融合权重和类别顺序。
- `fitguard_motion_v2_rf_blend_runtime.py`：板端入口。
- `fitguard_motion_v2_numpy_runtime.py`：特征提取和单森林运行时。
- `rf_blend_report.json`：全部权重与留一受试者结果。
- `runtime_benchmark.json`：纯NumPy速度检查。
