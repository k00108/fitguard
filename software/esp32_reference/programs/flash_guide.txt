============================================================
 烧到 ESP32 —— 两个固件，哪个烧哪块
============================================================

  bt_imu_node\bt_imu_node.ino       →  烧到【穿戴端】
                                        （焊了 MPU6050、用充电宝供电、戴身上的那块）

  bt_imu_bridge\bt_imu_bridge.ino   →  烧到【网关】
                                        （USB 线插到 PYNQ 的那块，放 PYNQ 旁边）

⚠️ 不要改这两个文件夹的名字！
   Arduino IDE 要求 .ino 文件名和它所在的文件夹名一致，
   改了文件夹名会打不开/编译报错。


------------------------------------------------------------
 烧写步骤（Arduino IDE）
------------------------------------------------------------
1) 装好 Arduino IDE + ESP32 支持包（开发板管理器搜 "esp32" by Espressif）
2) 开发板选：ESP32 Dev Module
3) 打开对应的 .ino，点"上传"
4) 打开串口监视器，波特率按下面填


------------------------------------------------------------
 穿戴端 bt_imu_node.ino —— 烧之前必须先改 3 个参数
------------------------------------------------------------
  ①  #define ODR_HZ  200          →  改成  50
      理由：模型窗口是 128 点 = 2.56 秒 × 50 Hz

  ②  mpuWrite(REG_GYRO_CONFIG, 0x08);  →  改成  0x00
      理由：你们的 fitguard_mpu6050.py 按 131 LSB/(°/s) 换算（±250 dps）；
            0x08 是 ±500 dps / 65.5 LSB，会让角速度差 2 倍

  ③  #define MIRROR_TO_USB  0     →  第一次自检改成 1
      理由：置 1 后会把蓝牙要发的同一批数据同时从 USB 吐出来，
            这样【不用蓝牙、不用网关、不用改 BD】就能先验证传感器和协议。
            串口监视器波特率用 921600
            ★ 第 4 步联调无线时，必须把它改回 0 重新烧一次

  其他参数不用动：
      #define TRANSPORT  TRANSPORT_BLE      ← 用蓝牙（默认）
      #define BATCH_N    5


------------------------------------------------------------
 网关 bt_imu_bridge.ino —— 不用改任何东西
------------------------------------------------------------
  默认就是 BLE 中心设备模式，串口监视器波特率 115200（看日志用）

  它要的输出（给 PYNQ 的那条线）是 921600，不用你设，代码里写好了。

  成功标志：
      启动时打印      ### FitGuard 外挂蓝牙网关启动
      也在扫描        ### 开始扫描 FitGuard-IMU
      连上了          ### BLE 已连接: xx:xx:xx:xx:xx:xx
      每 10 秒         ### 下行 xxx B  上行 xx B / x 帧  重连 0 次

  连不上时：
      1) 两块板子先放 1 米内
      2) 穿戴端的 DEVICE_NAME 必须是 "FitGuard-IMU"（和网关的 NODE_NAME 一致）
      3) 还是不行就把网关的 #define BRIDGE_MODE 改成 BRIDGE_MODE_SPP 重烧
         （经典蓝牙更稳，穿戴端不用改，它两种都支持）
